#E-Commerce Sales Performance Dashboard 📊
##An interactive Microsoft Excel dashboard built to analyze e-commerce sales performance and uncover actionable business insights.

#Key Features
- 📈 Monthly sales trend analysis
- 🛍️ Sales by product category and sales channel
- 📦 Order status and order volume analysis
- 👥 Customer demographics and gender analysis
- 🌍 State-wise sales performance
- 🎛️ Interactive PivotTables, PivotCharts, slicers, and timelines
- ⚙️ VBA macros for dashboard refresh, screen fitting, and date display

#Tools & Technologies
Microsoft Excel | PivotTables | PivotCharts | Slicers | Timelines | VBA Macros

#Objective
To transform raw e-commerce data into meaningful visual insights that support sales monitoring, performance analysis, and data-driven decision-making.
